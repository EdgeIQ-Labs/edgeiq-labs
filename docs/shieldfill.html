ShieldFill Documentation

AI-powered auto-fill for security questionnaires and RFPs using your organization's knowledge base.

Overview

ShieldFill is an AI-driven response engine that automatically fills security questionnaires, vendor risk assessments, and RFPs by retrieving answers from your uploaded knowledge base. It reduces manual effort in compliance and sales cycles by matching questionnaire prompts to verified source material.

  • Pricing: $499/month per organization (unlimited questionnaires, up to 500 MB knowledge base storage).
  • Core Function: Semantic retrieval + answer generation grounded exclusively in your documents.
  • Output: Draft responses with confidence scores and source citations for human review.

Getting Started

  1. Sign in at shieldfill.edgeiqlabs.com.
  2. Navigate to Settings → API Keys to generate credentials for integrations.
  3. Upload your initial knowledge base documents (see next section).
  4. Submit a test questionnaire to validate retrieval accuracy before production use.

Onboarding: New accounts include a 14-day trial with full feature access. No credit card required until conversion.

Uploading Knowledge Base

Your knowledge base is the sole source of truth for generated answers. ShieldFill does not use external training data for responses.

Supported Formats

FormatMax SizeNotes
PDF50 MBText layer required (scanned PDFs must be OCR'd first)
DOCX30 MBTables and headers preserved
Markdown (.md)10 MBIdeal for policy docs and runbooks
TXT10 MBPlain text only
CSV20 MBStructured Q&A pairs or control matrices

Upload Methods

  • Web UI: Drag-and-drop or file picker at Knowledge Base → Upload.
  • API: POST multipart/form-data to /api/v1/knowledge/documents.
  • Sync: Connect Google Drive or SharePoint for automatic nightly sync (Settings → Integrations).
curl -X POST https://api.shieldfill.edgeiqlabs.com/api/v1/knowledge/documents \
  -H "Authorization: Bearer sk_live_..." \
  -F "file=@security_policy_2026.pdf" \
  -F "tags=compliance,policies"

Accuracy Dependency: Outdated or contradictory documents degrade answer quality. Archive superseded files immediately.

Submitting Questionnaires

Questionnaires can be submitted as structured files or via manual entry.

Supported Input Formats

  • XLSX / CSV: Column A = question, optional Column B = category/context.
  • JSON: Array of objects with question and optional context fields.
  • Manual: Paste questions directly in the web UI.

Submission Workflow

  1. Upload questionnaire file or enter questions manually.
  2. Select target knowledge base tags (optional filter).
  3. Click Generate Responses. Processing time averages 2–5 seconds per question.
  4. Review draft answers in the Review Queue (see next section).
// JSON submission example
[
  { "question": "Describe your incident response process.", "context": "SOC 2 Type II" },
  { "question": "How is customer data encrypted at rest?" }
]

Reviewing Answers

All AI-generated answers require human validation before export. ShieldFill provides tooling to accelerate review without compromising accuracy.

  • Confidence Score: Each answer includes a 0–100% score based on retrieval relevance. Scores below 70% are flagged for priority review.
  • Source Citations: Click the citation link to jump to the exact passage in the source document.
  • Edit Inline: Modify any answer directly in the review queue. Edits are tracked in version history.
  • Approve / Reject: Mark answers as approved or rejected. Rejected answers return to the queue with reviewer notes.
  • Bulk Actions: Select multiple answers to approve, reject, or re-generate with adjusted parameters.

Export: Approved answers can be exported in the original questionnaire format (XLSX, CSV, JSON) or as a formatted PDF report.

Integrations

REST API

All ShieldFill functionality is available via REST API. Authenticate with Bearer tokens from Settings → API Keys.

# Submit questionnaire programmatically
curl -X POST https://api.shieldfill.edgeiqlabs.com/api/v1/questionnaires \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"questions": ["Describe access control policies."], "kb_tags": ["compliance"]}'

Webhooks

Configure webhooks at Settings → Webhooks to receive events when processing completes or reviews are finalized.

EventPayload KeyDescription
questionnaire.completedquestionnaire_idAll questions processed; ready for review
review.finalizedquestionnaire_idAll answers approved/rejected; export available
kb.sync_completedsync_idExternal knowledge base sync finished
 
// Webhook payload example
{
  "event": "questionnaire.completed",
  "questionnaire_id": "qn_abc123",
  "total_questions": 42,
  "avg_confidence": 0.87,
  "review_url": "https://shieldfill.edgeiqlabs.com/review/qn_abc123"
}
