Setup

Branding Configuration

Configure your brand identity once; all generated reports inherit these settings automatically.

# Set primary brand color (hex)
report-builder config set brand.primary_color "#0A84FF"

# Set secondary/accent color
report-builder config set brand.secondary_color "#1E1E2E"

# Set company name and tagline
report-builder config set brand.company_name "Acme Security Partners"
report-builder config set brand.tagline "Trusted Cybersecurity Services"

# Set contact information
report-builder config set brand.email "reports@acmesecurity.com"
report-builder config set brand.phone "+1 (555) 012-3456"
report-builder config set brand.website "https://acmesecurity.com"

Logo Upload

Upload your logo in PNG or SVG format. Recommended dimensions: 400×120px for header, 200×200px for cover page.

# Upload header logo
report-builder branding upload-logo ./logo-header.png --position header

# Upload cover page logo
report-builder branding upload-logo ./logo-cover.svg --position cover

# Preview current branding
report-builder branding preview
Logos are automatically resized to fit template constraints. SVG logos render crisply at any resolution. Maximum file size: 2MB.

Template Editor

The template editor provides a visual interface for customizing report structure, sections, and styling without editing raw configuration files.

# Open interactive template editor
report-builder template edit default

# List available templates
report-builder template list

# Create a new template from existing
report-builder template clone default pentest-report

# Export template as JSON for version control
report-builder template export pentest-report > pentest-template.json

# Import template from JSON
report-builder template import pentest-template.json

Automated Scheduling

Schedule recurring report generation and delivery to clients or internal stakeholders.

# Schedule monthly report for a client
report-builder schedule add \
  --client "Acme Corp" \
  --template pentest-report \
  --cron "0 9 1 * *" \
  --deliver-email admin@acmecorp.com

# Schedule weekly internal summary
report-builder schedule add \
  --client "Internal" \
  --template executive-summary \
  --cron "0 8 * * 1" \
  --deliver-webhook https://hooks.slack.com/services/xxx

# List active schedules
report-builder schedule list

# Pause a schedule
report-builder schedule pause schedule-id-abc123

# Test delivery without generating full report
report-builder schedule test-delivery schedule-id-abc123
Schedules use server-local timezone. Use ISO 8601 cron expressions. Failed deliveries retry up to 3 times with exponential backoff.

Client Portal

Provide clients with secure, self-service access to their reports without requiring direct email delivery.

# Enable portal for a client
report-builder portal enable --client "Acme Corp"

# Generate portal invite link
report-builder portal invite --client "Acme Corp" --email admin@acmecorp.com

# List portal users
report-builder portal users list

# Revoke portal access
report-builder portal revoke --user user-id-xyz789

# Configure portal branding
report-builder portal config set custom_domain reports.acmesecurity.com
report-builder portal config set login_logo ./portal-logo.png

Portal Features

  • Secure login with magic link or SSO (SAML/OIDC)
  • Report download in PDF or interactive HTML
  • Historical report archive with search
  • Comment threads on individual findings
  • Custom domain and branding support

Troubleshooting

Common Issues

Logo not appearing in generated PDF: Verify upload succeeded with report-builder branding preview. Check file format (PNG/SVG only) and ensure dimensions don't exceed 2000px on any side.

Scheduled reports not delivering: Test delivery with report-builder schedule test-delivery <id>. Check SMTP/webhook credentials and review ~/.edgeiq/logs/scheduler.log for errors.

Portal login fails: Confirm user was created with valid email. Check spam folder for magic link. For SSO, verify IdP metadata URL and attribute mapping.

Template changes not reflected: Templates are cached. Run report-builder template reload or restart the service after manual edits.

PDF generation timeout: Large reports with many findings may exceed default 60s timeout. Increase with report-builder config set pdf.timeout 120.
