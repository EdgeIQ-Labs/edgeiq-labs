Weekly compliance monitoring is live

Your domain is now scanned every Monday. Here's what happens next:

1
First scan runs now — baseline compliance check is running against your domain. Results stored in the cloud.
2
Weekly digest every Monday — at 8:00 AM UTC you'll receive a full compliance report with score, grade, and control breakdown.
3
Score trend tracking — every scan is compared to the previous week. If your score drops or a new issue appears, you'll know immediately.
4
Run manual scans anytime — visit the compliance dashboard to run an on-demand scan outside of your weekly schedule.

Checks run every week

  • HTTPS + TLS active
  • HSTS header + max-age
  • HTTP → HTTPS redirect
  • Content-Security-Policy
  • X-Frame-Options
  • X-Content-Type-Options
  • Referrer-Policy
  • Permissions-Policy
  • Server header exposure
  • SPF DNS record
  • DMARC record + policy
  • MX records
