# Blog Post Pre-Publish Checklist

Run through this before publishing any new blog post. Adapted from Yoast methodology for static HTML sites.

## SEO Basics
- [ ] Focus keyword appears in `<title>` tag
- [ ] Focus keyword appears in `<meta name="description">`
- [ ] Focus keyword appears in H1 heading
- [ ] Focus keyword appears in first paragraph
- [ ] Meta description is 50-160 characters
- [ ] Title tag is under 60 characters
- [ ] Canonical URL is set correctly
- [ ] OG and Twitter meta tags are populated

## Content Quality
- [ ] Post is 800-1200 words (sweet spot for ranking)
- [ ] Readability pass completed (run through humanizer skill)
- [ ] No passive voice overuse
- [ ] Sentences vary in length (mix short punchy + longer explanatory)
- [ ] Technical jargon explained in plain language
- [ ] Paragraphs are 2-4 sentences max

## Internal Linking
- [ ] 5+ internal links to related posts or product pages
- [ ] Links to relevant pillar/cornerstone content
- [ ] At least 1 link to a free tool page
- [ ] At least 1 link to a paid service or pricing page
- [ ] Anchor text is descriptive (not "click here")

## Structure & UX
- [ ] Table of Contents added if post >1500 words
- [ ] Images every 300 words with descriptive alt text
- [ ] H2/H3 hierarchy is logical (no skipping levels)
- [ ] CTA box at end linking to relevant paid service
- [ ] Email capture form included (Substack signup)

## Schema Markup
- [ ] Article JSON-LD schema present
- [ ] FAQ schema added if post answers specific questions
- [ ] BreadcrumbList schema included
- [ ] Author and datePublished fields populated

## Technical
- [ ] File uses kebab-case naming (e.g., `managed-vps-guide.html`)
- [ ] Design system CSS linked (`/css/design-system.css?v=10`)
- [ ] Theme script included (`/js/theme.js`)
- [ ] `data-theme="dark"` set on `<html>` tag
- [ ] Umami analytics script present
- [ ] Mobile responsive (test at 375px width)
