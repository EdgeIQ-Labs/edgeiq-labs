VPS Connection Guide

How to access your EdgeIQ VPS container via browser terminal or SSH client.

RECOMMENDED Browser Terminal

No software installation required. Works in any modern browser (Chrome, Firefox, Safari, Edge).

  1. Go to https://vps-ssh.edgeiqlabs.com
  2. Enter the email address you used when signing up for your EdgeIQ VPS plan
  3. Click "Send login code"
  4. Check your inbox for a 6-digit code from Cloudflare (check spam if you don't see it within a minute)
  5. Enter the code on the login page
  6. You'll be connected directly to your VPS container's root terminal

Security: The browser terminal uses Cloudflare Access with email OTP authentication. No passwords are sent over the wire during login. Your session is encrypted end-to-end through Cloudflare's tunnel network.

CLI SSH (Advanced Users)

If you prefer using your own terminal app (kitty, ghostty, iTerm2, Windows Terminal, PowerShell, etc.), you have two options:

Option A: Direct SSH (uses your assigned port)

Your welcome email includes a unique SSH port assigned to your container. Connect directly:

ssh root@vps.edgeiqlabs.com -p YOUR_SSH_PORT

Replace YOUR_SSH_PORT with the port number from your welcome email. Enter your root password when prompted.

Option B: Via Cloudflare Tunnel (no port needed)

This method routes through the same secure tunnel as the browser terminal. Requires installing cloudflared first:

  • macOS: brew install cloudflared
  • Linux (Debian/Ubuntu): 
    curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt update && sudo apt install cloudflared
  • Windows: Download from Cloudflare Downloads

Then connect using ProxyCommand:

ssh -o ProxyCommand="cloudflared access ssh --hostname %h" root@vps-ssh.edgeiqlabs.com

You'll be prompted for your email → receive a login code via email → enter it → connected to your container.

Troubleshooting

ProblemFix
"Site can't be reached" (browser)Clear browser cache or try an incognito/private window
Login code not arrivingCheck spam folder. Ensure you're using the exact email you signed up with
SSH connection refused (CLI)Verify you're using the correct port from your welcome email
"Permission denied"Make sure you're logging in as root, not your email username
Terminal appears blank after authWait 5-10 seconds; the jump host needs a moment to route to your container
Still stuckReply to your welcome email or join our Discord

Security Notes

  • Your VPS container is fully isolated — you only have access to your own environment
  • The browser terminal uses Cloudflare Access (email OTP), so no static passwords are transmitted during authentication
  • We recommend changing your root password after first login: run passwd
  • Keep your welcome email credentials safe — they contain your unique port and password
  • All traffic is encrypted through Cloudflare's tunnel network; your connection never touches the public internet directly

Important: Never share your login code or root password with anyone. EdgeIQ staff will never ask for your password.
