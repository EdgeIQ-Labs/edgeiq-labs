Overview

Vendor Watch continuously monitors third-party vendors for security incidents, compliance violations, breach disclosures, and risk posture changes. Designed for procurement teams, CISOs, and compliance officers managing supply chain risk without manual questionnaires or point-in-time assessments.

  • Track unlimited vendors across industries and regions
  • Automated security rating based on public signals
  • Detect breaches, CVEs, and regulatory actions in real time
  • Monitor SOC 2, ISO 27001, GDPR, and HIPAA compliance status
  • Instant alerts via email, webhook, Slack, or Discord
  • REST API for GRC platform integration and automated reporting

Setup

Adding Vendors to Monitor

# Add a single vendor by domain
vendor-watch add acme-corp.com

# Add multiple vendors from CSV
vendor-watch add --file vendors.csv

# Import from existing GRC platform
vendor-watch import --source onetrust --api-key YOUR_KEY

# List monitored vendors
vendor-watch list

Configuring Alert Channels

# Email alerts
vendor-watch config --alert-email security@example.com

# Webhook (generic)
vendor-watch config --alert-webhook https://hooks.example.com/vendor-watch

# Slack integration
vendor-watch config --slack-webhook https://hooks.slack.com/services/xxx

# Discord integration
vendor-watch config --discord-webhook https://discord.com/api/webhooks/xxx

# Test alert delivery
vendor-watch test-alert
Multiple alert channels can be configured simultaneously. All channels receive identical payloads for audit consistency.

Troubleshooting

Common Issues

Vendor not found: Verify the domain is correct and publicly resolvable. Use vendor-watch check acme-corp.com to run a one-off assessment including DNS validation, certificate analysis, and breach database lookup.

Risk score seems inaccurate: Scores are based on public signals only. Private infrastructure and internal controls are not visible. Supplement with manual questionnaire data via vendor-watch update acme-corp.com --manual-score 85.

Alerts not delivering: Test with vendor-watch test-alert. Check ~/.edgeiq/logs/vendor-watch.log for SMTP errors, webhook HTTP status codes, or rate-limit responses from notification providers.

Compliance status outdated: Certification databases may lag. Manually verify via auditor reports and update with vendor-watch compliance set acme-corp.com --framework soc2 --status valid --expiry 2027-03-01.

Too many false positives: Narrow breach feeds to curated only. Adjust --risk-threshold to reduce noise from minor score fluctuations. Enable --debounce 2 to require confirmation before alerting.
