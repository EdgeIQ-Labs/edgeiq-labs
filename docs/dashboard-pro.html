Setup

Connecting Scanner APIs

Dashboard Pro ingests data from any EdgeIQ scanner running in API mode or via direct database connection.

# Start your scanner in API mode
port-scanner serve --port 8400 --api-key YOUR_API_KEY

# In Dashboard Pro UI: Settings → Data Sources → Add Source
#   Type: EdgeIQ Port Scanner
#   URL: http://scanner-host:8400
#   API Key: YOUR_API_KEY
#   Poll Interval: 300s

# Or connect via CLI
dashboard-pro source add \
  --name "prod-scanner" \
  --type edgeiq-port-scanner \
  --url http://scanner-host:8400 \
  --api-key YOUR_API_KEY \
  --interval 300
API keys are stored encrypted at rest. Use read-only keys when possible. Dashboard Pro never writes back to scanner APIs.

Custom Dashboards

Build dashboards by dragging widgets onto a grid canvas. Each widget binds to a data source query and supports filtering, aggregation, and threshold-based coloring.

Widget TypeDescriptionBest For
Stat CardSingle metric with delta indicatorTotal open ports, critical count
Time SeriesLine/area chart over timePort exposure trends
Bar ChartCategorical comparisonTop hosts by risk score
HeatmapGrid intensity mapPort/service density by subnet
TableSortable paginated rowsLive high-risk port list
GaugeRadial progress indicatorCompliance percentage
Alert FeedReal-time event streamNew critical findings
# Create dashboard via CLI
dashboard-pro dashboard create "Network Posture" \
  --layout 3x4 \
  --source prod-scanner

# Add widget
dashboard-pro widget add "Network Posture" \
  --type time-series \
  --query "open_ports_count" \
  --range 30d \
  --position 0,0,2,1

Trend Analysis

Track security metrics over time to identify regression, measure remediation velocity, and forecast risk exposure.

  • Configurable granularity: hourly, daily, weekly, monthly
  • Baseline comparison against historical averages
  • Anomaly detection with configurable sensitivity
  • Exportable CSV/JSON for external BI tools
# Query trend data via API
curl -H "Authorization: Bearer $DASH_API_KEY" \
  "https://app.edgeiqlabs.com/api/v1/trends/open_ports?range=90d&granularity=daily"

Executive Reports

Generate polished PDF/HTML reports for stakeholders without dashboard access. Schedule automatic delivery or trigger on-demand.

# Create report template
dashboard-pro report create "Weekly Security Summary" \
  --dashboard "Network Posture" \
  --include-trends \
  --include-high-risk-table \
  --format pdf

# Schedule weekly delivery
dashboard-pro report schedule "Weekly Security Summary" \
  --cron "0 8 * * 1" \
  --recipients ciso@example.com,secops@example.com

# Generate immediately
dashboard-pro report run "Weekly Security Summary" --download ./report.pdf
Reports render server-side. Large dashboards may take 30-60 seconds. Use --async for non-blocking generation with webhook callback.

Troubleshooting

Common Issues

Data source shows "unreachable": Verify the scanner API is running (curl http://scanner-host:8400/health). Check firewall rules and API key validity.

Widgets display stale data: Confirm poll interval isn't too long. Check dashboard-pro source status <name> for last successful fetch timestamp.

Slack/Teams notifications not arriving: Test with dashboard-pro integration test <name>. Verify webhook URL hasn't expired. Check rate limits on the platform side.

Report generation times out: Reduce dashboard complexity or use --async flag. Server-side rendering has a 120s default timeout; contact support to increase for Agency plans.

Trend charts show gaps: Missing data points indicate scanner downtime or API errors during that window. Check scanner logs and Dashboard Pro ingestion logs at ~/.edgeiq/logs/dashboard.log.
