Overview

Compliance Posture Tracker is a lightweight compliance monitoring tool designed for small businesses and startups. It scans your infrastructure against common compliance frameworks (SOC 2, HIPAA, PCI-DSS) and generates actionable gap analysis reports. Distinct from the enterprise-grade Compliance Shield ($299/mo), this tool focuses on affordability and simplicity for teams that need continuous compliance visibility without enterprise overhead.

  • Automated scanning against SOC 2, HIPAA, and PCI-DSS controls
  • Control-by-control pass/fail/warning status with priority ranking
  • Auto-gathered evidence: logs, configs, DNS records, TLS certificates
  • Trend tracking with score history and regression alerts
  • PDF and CSV export for auditors and stakeholders
  • REST API for CI/CD integration and custom workflows

Setup

Connecting Cloud Accounts

Connect your cloud providers to enable automated evidence collection and infrastructure scanning:

# Connect AWS account
compliance-tracker connect aws --role-arn arn:aws:iam::123456789012:role/ComplianceScanner

# Connect GCP project
compliance-tracker connect gcp --project my-project-id --service-account sa@my-project.iam.gserviceaccount.com

# Connect Azure subscription
compliance-tracker connect azure --subscription-id xxxxx-xxxxx-xxxxx

# List connected accounts
compliance-tracker connections list
Cloud connections use read-only IAM roles. No write permissions are required or requested.

Defining Scope

Define which domains, IPs, and cloud resources are in scope for compliance scanning:

# Add domain to scope
compliance-tracker scope add domain example.com

# Add CIDR range
compliance-tracker scope add network 10.0.0.0/24

# Add specific cloud resource
compliance-tracker scope add resource aws:s3:my-compliance-bucket

# View current scope
compliance-tracker scope list

Framework Selection

Select one or more compliance frameworks to scan against. Each framework includes a curated checklist of technical controls mapped to regulatory requirements.

# Set default framework
compliance-tracker config set default_framework soc2

Gap Analysis

After each scan, Compliance Posture Tracker identifies missing or misconfigured controls and ranks them by priority based on risk severity and regulatory impact.

Priority Levels

LevelColorDescriptionAction Window
CriticalRedControl failure exposes sensitive data or violates core requirementFix within 48 hours
HighOrangeSignificant gap that increases audit riskFix within 2 weeks
MediumYellowPartial implementation or weak configurationFix within 30 days
LowGreenMinor improvement opportunityNext review cycle
# View gap analysis report
compliance-tracker gaps example.com --framework soc2

# Filter by priority
compliance-tracker gaps example.com --priority critical,high

# Export gap list
compliance-tracker gaps example.com --export gaps.csv

Evidence Collection

Compliance Posture Tracker automatically gathers evidence required for audits, including configuration snapshots, log excerpts, DNS records, and TLS certificate details.

Evidence Types

  • DNS Records: SPF, DMARC, MX, CNAME configurations
  • TLS Certificates: Validity dates, cipher suites, HSTS headers
  • HTTP Headers: CSP, X-Frame-Options, Referrer-Policy, Permissions-Policy
  • Server Configs: Exposed version strings, X-Powered-By headers
  • Cloud Configs: S3 bucket policies, security group rules, IAM policies
  • Log Samples: Access logs, audit trails, error patterns
# Collect evidence for a domain
compliance-tracker evidence collect example.com --framework soc2

# View collected evidence
compliance-tracker evidence list example.com

# Download evidence bundle
compliance-tracker evidence download example.com --output ./evidence-bundle.zip
Evidence is stored encrypted at rest. Retention defaults to 90 days; configure with compliance-tracker config set evidence_retention_days 365.

API Reference

All CLI functionality is available via REST API when running compliance-tracker serve --port 8401.

Endpoints

MethodPathDescription
GET/api/compliance/statusGet current compliance posture for a domain
POST/api/compliance/scanInitiate a new compliance scan
GET/api/compliance/gaps/{domain}Retrieve gap analysis results
GET/api/compliance/evidence/{domain}List collected evidence artifacts
POST/api/compliance/exportGenerate PDF/CSV report
GET/api/compliance/history/{domain}Retrieve scan history and trend data

Example: Get Compliance Status

curl -X GET "http://localhost:8401/api/compliance/status?domain=example.com&framework=soc2" \
  -H "Authorization: Bearer YOUR_API_KEY"

Example: Trigger Scan via API

curl -X POST http://localhost:8401/api/compliance/scan \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "domain": "example.com",
    "framework": "soc2",
    "collect_evidence": true
  }'

Report Export

Generate auditor-ready reports in PDF or CSV format. Reports include executive summary, control breakdown, gap analysis, evidence references, and trend charts.

# Export PDF report
compliance-tracker report export example.com --format pdf --output compliance-report.pdf

# Export CSV for spreadsheet analysis
compliance-tracker report export example.com --format csv --output compliance-data.csv

# Include evidence links in report
compliance-tracker report export example.com --format pdf --include-evidence

# Schedule weekly report generation
compliance-tracker report schedule example.com --weekly --email admin@example.com
PDF reports include embedded evidence screenshots and timestamped scan metadata for audit trail verification.

Troubleshooting

Common Issues

Scan fails with "connection timeout": Verify DNS resolution and network connectivity. Check if firewall rules block outbound HTTPS (port 443). Use --timeout 30 to increase wait time.

Missing evidence for cloud resources: Verify IAM role has read permissions for the target service. Run compliance-tracker connections verify aws to test access.

False positive on control check: Some controls require manual verification. Mark as accepted risk with compliance-tracker gaps accept CONTROL_ID --reason "Compensating control in place".

Score not updating after fix: Evidence cache may be stale. Force refresh with compliance-tracker evidence refresh example.com before re-scanning.

API returns 401 Unauthorized: Verify API key is valid and not expired. Regenerate with compliance-tracker api-key rotate.

PDF export fails: Ensure sufficient disk space in temp directory. Large evidence bundles may require --max-evidence-size 50MB flag.
