    Frequently asked questions

    Is this safe? Does my password get sent anywhere?
    Your password is hashed in your browser using SHA-1 before anything leaves your device. Only the first 5 characters of the hash are sent to the Have I Been Pwned API (this is called k-anonymity). The server returns all hashes matching that prefix, and your browser checks if the remaining hash suffix is in the list. Your actual password is never transmitted and cannot be reconstructed from the hash.
    What does "found in X breaches" mean?
    It means your exact password has appeared in X publicly-known data breach dumps collected by Have I Been Pwned. This doesn't necessarily mean your specific account was breached — but anyone using this password on any site is at risk because attackers use these leaked password lists for automated credential stuffing attacks across thousands of websites.
    What makes a strong password?
    A strong password is at least 12 characters long, uses a mix of uppercase letters, lowercase letters, numbers, and special characters, and is completely unique to each account. The most effective approach is using a password manager like Bitwarden to generate and store random 16+ character passwords for every site — you only need to remember one master password.
    Should I use this tool with my real passwords?
    Yes — the tool is designed to be safe for real passwords thanks to the k-anonymity model. However, if you're uncomfortable entering any password into a web form (even one that hashes locally), you can download the HIBP password database and check offline, or use a password manager's built-in breach checking feature.
