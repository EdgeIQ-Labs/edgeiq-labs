ShieldInvoice Documentation

AI-powered invoice processing and accounts payable automation for SMB accounting teams.

Overview

ShieldInvoice automates accounts payable workflows by extracting structured data from PDF invoices using AI. It identifies vendors, line items, totals, tax amounts, and PO numbers automatically, flags duplicates and anomalies, and exports clean data to CSV or QuickBooks Online.

  • Pricing: $149/month (Starter) or $299/month (Pro). No per-invoice overages on Pro.
  • Core Function: OCR + semantic extraction grounded in invoice structure patterns.
  • Output: Structured JSON with confidence scores, anomaly flags, and audit trail.

Getting Started

  1. Sign up at edgeiqlabs.com/shieldinvoice.
  2. Navigate to Dashboard → Settings → API Keys to generate credentials for integrations.
  3. Upload a test invoice via the dashboard or API to validate extraction accuracy.
  4. Configure export preferences (CSV or QuickBooks Online) under Settings → Integrations.

Onboarding: New accounts include a live demo with sample invoices. Contact billing@edgeiqlabs.com for a guided walkthrough tailored to your invoice formats.

Authentication

All API requests require authentication via API key or session token.

API Key

Include your API key in the Authorization header as a Bearer token:

Authorization: Bearer si_live_abc123xyz

Session Token

For browser-based integrations, use session cookies obtained after login at /shieldinvoice/dashboard. Session tokens expire after 24 hours of inactivity.

Security: Never expose API keys in client-side code. Use environment variables or secret managers for server-side integrations.

API Reference

Base URL: https://edgeiqlabs.com/api/shieldinvoice

Process Invoice

Upload a PDF invoice for AI extraction.

MethodEndpointDescription
POST/api/shieldinvoice/processUpload and process a single invoice

Request

  • Content-Type: multipart/form-data
  • Parameters:
    • file (required): PDF file (max 20 MB)
    • vendor_hint (optional): Expected vendor name for improved matching
    • po_number (optional): Expected PO number for validation
curl -X POST https://edgeiqlabs.com/api/shieldinvoice/process \
  -H "Authorization: Bearer si_live_abc123xyz" \
  -F "file=@invoice_2026_001.pdf" \
  -F "vendor_hint=Acme Corp"

Response

{
  "invoice_id": "inv_7f8g9h",
  "status": "processed",
  "extracted": {
    "vendor": "Acme Corporation",
    "invoice_number": "INV-2026-001",
    "date": "2026-11-15",
    "due_date": "2026-12-15",
    "subtotal": 1250.00,
    "tax": 100.00,
    "total": 1350.00,
    "po_number": "PO-9876",
    "line_items": [
      { "description": "Widget A", "quantity": 10, "unit_price": 125.00, "total": 1250.00 }
    ]
  },
  "confidence": 0.96,
  "anomalies": [],
  "created_at": "2026-11-18T14:32:00Z"
}

List Invoices

Retrieve a paginated list of processed invoices.

MethodEndpointDescription
GET/api/shieldinvoice/invoicesList all invoices with optional filters

Query Parameters

  • limit (integer, default 20): Results per page (max 100)
  • offset (integer, default 0): Pagination offset
  • vendor (string): Filter by vendor name
  • status (string): Filter by status (processed, flagged, exported)
  • from_date / to_date (ISO 8601): Date range filter
curl -X GET "https://edgeiqlabs.com/api/shieldinvoice/invoices?limit=10&vendor=Acme" \
  -H "Authorization: Bearer si_live_abc123xyz"

Get Invoice Detail

Retrieve full extraction details for a specific invoice.

MethodEndpointDescription
GET/api/shieldinvoice/invoices/[id]Get detailed extraction results
 
curl -X GET https://edgeiqlabs.com/api/shieldinvoice/invoices/inv_7f8g9h \
  -H "Authorization: Bearer si_live_abc123xyz"

Export Invoices

Export processed invoices to CSV or QuickBooks Online format.

MethodEndpointDescription
POST/api/shieldinvoice/exportGenerate export file for selected invoices

Request Body

{
  "invoice_ids": ["inv_7f8g9h", "inv_4d5e6f"],
  "format": "csv",
  "include_line_items": true
}

Supported Formats

  • csv: Standard CSV with headers (all plans)
  • qbo: QuickBooks Online IIF format (Pro plan only)
curl -X POST https://edgeiqlabs.com/api/shieldinvoice/export \
  -H "Authorization: Bearer si_live_abc123xyz" \
  -H "Content-Type: application/json" \
  -d '{"invoice_ids": ["inv_7f8g9h"], "format": "csv"}'

Dashboard Guide

The ShieldInvoice dashboard at /shieldinvoice/dashboard provides a visual interface for managing invoices.

Key Features

  • Invoice List: Searchable table with vendor, date, total, status, and confidence score columns. Click any row to view details.
  • Anomaly Flags: Yellow warning icons indicate potential issues (duplicate invoice numbers, amount mismatches, missing PO). Click the flag to see explanation.
  • Bulk Actions: Select multiple invoices to export, archive, or re-process with adjusted parameters.
  • Analytics: Monthly spend by vendor, processing volume trends, and average confidence scores.
  • Email Ingest: Your unique ingest address appears under Settings → Email Ingest. Forward PDFs directly from your email client.

Keyboard Shortcuts: Press / to focus search, E to export selected, R to refresh the list.
