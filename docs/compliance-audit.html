Overview

The Compliance Audit is EdgeIQ Labs’ premium security assessment tier. Unlike the automated $49 Compliance Report Generator or the free scan, this service combines comprehensive automated scanning with human analyst review to deliver a complete security posture assessment suitable for board presentations, vendor due diligence, and regulatory compliance evidence.

  • Price: $499 one-time per domain.
  • Billing: Single payment via Stripe; no subscription required.
  • Delivery: Full report delivered within 24 hours of payment confirmation.
  • Data handling: Scan data is processed securely and retained only for report generation. Raw data is purged after delivery unless you opt into extended retention for re-audits.
  • Supported frameworks: SOC 2, HIPAA, PCI-DSS, NIST CSF, GDPR, ISO 27001, and custom frameworks on request.

What’s Included

Full Security Assessment

We execute 200+ security checks across network, application, infrastructure, and configuration layers. This includes port scanning, TLS analysis, header inspection, DNSSEC validation, API endpoint testing, cloud storage exposure checks, and dependency vulnerability correlation. Every finding is validated to reduce false positives.

Prioritized Remediation Playbook

Each finding includes severity ranking (CVSS v3.1), business impact context, specific code-level fix guidance, implementation effort estimates (hours/days), and responsible team assignment suggestions. Findings are ordered by risk-adjusted priority, not just severity score.

Compliance Mapping Matrix

A detailed cross-reference table mapping every finding to relevant controls in SOC 2, HIPAA, PCI-DSS, NIST CSF, and other applicable frameworks. Includes gap analysis showing which controls are satisfied, partially met, or missing entirely. Specific control references (e.g., "SOC 2 CC6.1", "HIPAA §164.312(a)(1)") are cited for auditor readiness.

Executive Summary

A polished 2-3 page overview designed for non-technical stakeholders. Includes overall risk rating, trend indicators (if historical data exists), top 5 strategic recommendations, budget allocation guidance, and compliance readiness status. Delivered as print-ready PDF with professional formatting.

Verified Badge Eligibility

Audit customers achieving A or B grade qualify for the EdgeIQ Verified Badge at no additional cost for the first year ($99 value). The badge demonstrates independently verified security posture to customers, partners, and regulators.

Setup & Ordering

  1. Visit the landing page: Navigate to /compliance-audit/ or /compliance-report/ (upsell tier).
  2. Enter target domain: Provide the primary domain to audit (e.g., example.com). Subdomains are automatically discovered and included.

  5. Receive confirmation: After payment, you receive an immediate email confirming receipt and estimated delivery window (within 24 hours).
  6. Download report: Once ready, you receive a second email with a secure download link. Links expire after 7 days for security.

API Reference

For programmatic integration or reseller workflows, the Compliance Audit exposes REST endpoints. Base URL: https://api.edgeiqlabs.com/v1/audit. Authenticate via Bearer token from your dashboard.

Initiate Audit

POST /v1/audit/initiate
Content-Type: application/json
Authorization: Bearer ***

{
  "domain": "example.com",
  "email": "security@example.com",
  "frameworks": ["SOC2", "HIPAA"],
  "priority": "standard"

Returns {"audit_id": "aud_xyz789", "status": "queued", "estimated_delivery": "2026-11-20T15:00:00Z"}.

Download Report

GET /api/compliance-report/download?id={report_id}
Authorization: Bearer ***

Returns binary PDF stream. Set Accept: application/pdf header. Download URLs expire after 7 days.

Stripe Checkout Integration

GET /api/compliance-audit-checkout?email={encoded_email}&domain={encoded_domain}

Redirects to Stripe Checkout session. On success, Stripe redirects back to your configured success URL with ?session_id={sess_xxx}. Verify session server-side before granting access.

Troubleshooting

  • Checkout fails or loops: Ensure email and domain fields contain valid values without leading/trailing whitespace. Disable browser extensions that block Stripe scripts. Try incognito mode if issues persist.
  • Report not received within 24 hours: Check spam/junk folders first. If still missing, contact support with your Stripe session ID or receipt number. Delays may occur during high-volume periods but never exceed 48 hours.
  • Download link expired: Links expire after 7 days for security. Request a fresh link via the support portal using your original order email. Re-issuance is free within 30 days of purchase.
  • Findings seem incorrect: Use your included follow-up exchange to request clarification. Include specific finding IDs and evidence screenshots. Analysts respond within 1 business day.
  • Framework mapping incomplete: Specify all relevant frameworks during checkout. Custom frameworks require advance notice; contact sales before purchasing if you need non-standard mappings (e.g., FedRAMP, CMMC).
  • API returns 401 Unauthorized: Verify Bearer token hasn’t expired. Tokens rotate every 90 days; regenerate from dashboard → API Keys. Never share tokens or embed in client-side code.
  • Grade differs from free scan: Expected. The audit uses deeper checks, manual validation, and contextual risk adjustment. Free scans show surface-level posture; audits reveal true organizational risk.
  • Badge not appearing after qualifying: Wait 24 hours post-delivery for badge eligibility propagation. Verify score ≥ B in report. Embed code is sent separately; check inbox for "Your EdgeIQ Verified Badge" email.
