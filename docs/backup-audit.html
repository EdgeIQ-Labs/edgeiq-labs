Overview

Backup Audit Tool analyzes your backup configuration files or logs and generates an instant compliance grade (A-F) based on industry best practices. All processing happens entirely in your browser — no data is uploaded to our servers.

  • Checks encryption-at-rest and in-transit settings
  • Validates offsite/cloud copy requirements (3-2-1 rule)
  • Audits retention policies against compliance frameworks
  • Verifies test restore evidence and frequency
  • Detects immutable/air-gapped backup configurations
  • Generates actionable remediation checklist

Setup

Using the Web Tool

No installation required. Simply visit /backup-audit/ and upload your backup configuration file:

# Supported formats:
# - Veeam Backup & Replication XML/JSON configs
# - AWS Backup JSON policies
# - Azure Backup XML configurations
# - Restic/Borg/Kopia config files
# - Generic backup logs (text/csv)

# Or paste raw config text directly into the tool
All parsing runs locally in your browser via JavaScript. Your backup configuration never leaves your machine.

CLI Alternative

For automated pipelines or bulk auditing, use the CLI version:

# Install via npm
npm install -g @edgeiq/backup-audit

# Audit a single config file
backup-audit check ./veeam-config.xml

# Audit all configs in a directory
backup-audit check ./backups/ --recursive

# Export results as JSON
backup-audit check ./config.json --output results.json

# Compare against specific framework
backup-audit check ./policy.json --framework hipaa

Supported Frameworks

Select a compliance framework to adjust grading weights and retention minimums:

  • SOC 2: CC7.1, CC7.2 — 7-year retention default
  • HIPAA: §164.310(a)(2)(ii) — 6-year retention minimum
  • PCI-DSS: Req 12.10 — 1-year retention, quarterly restores
  • GDPR: Art. 32 — Encryption mandatory, right-to-delete support
  • General Best Practice: 3-2-1 rule, no framework-specific retention

Troubleshooting

Common Issues

File not recognized: Ensure your config file matches a supported format. Try converting to JSON/XML first. Use backup-audit detect ./file.txt to identify format.

Grade seems too low/high: Verify you selected the correct compliance framework. General best practice uses different weights than HIPAA/SOC2. Check category breakdown for specific failures.

Browser hangs on large files: Files over 10MB may cause performance issues. Split multi-server configs into individual files or use the CLI version.

False positive on encryption check: Some tools use non-standard cipher names. Manually verify with backup-audit explain --category encryption to see detection logic.

CLI returns "no configs found": Verify file extensions match supported types. Use --force flag to attempt parsing unrecognized formats.

Need help interpreting results: Each failed check includes a remediation link. For complex environments, consider our paid Compliance Posture Tracker ($9/mo) for continuous monitoring.
