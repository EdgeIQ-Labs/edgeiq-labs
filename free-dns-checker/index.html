Frequently asked questions

What is a DNS A record?
An A record maps a domain name to an IPv4 address. When you visit example.com, your browser queries DNS for the A record to find which server IP to connect to. Multiple A records enable round-robin load balancing.
What is the difference between A and AAAA records?
A records map to IPv4 addresses (e.g., 93.184.216.34), while AAAA records map to IPv6 addresses (e.g., 2606:2800:220:1:248:1893:25c8:1946). Modern domains should have both for dual-stack support. IPv6 adoption is growing but IPv4 is still dominant.
What does a CNAME record do?
A CNAME (Canonical Name) record creates an alias from one domain to another. For example, www.example.com might CNAME to example.com. Important: CNAMEs cannot coexist with other record types at the same name, and should never be used at the zone apex (bare domain).
What are MX records?
MX (Mail Exchange) records specify which mail servers accept email for a domain. Each MX record has a priority number — lower numbers indicate higher priority. Mail is delivered to the lowest-priority server first, with others as fallbacks.
Why should I check my DNS records regularly?
DNS misconfigurations cause email delivery failures (missing MX or SPF records), website outages (wrong A records after migration), security issues (missing CAA records allowing unauthorized certificate issuance), and subdomain takeovers (dangling CNAME records pointing to decommissioned services).
