Overview

Business Listing Aggregator continuously monitors your business presence across directories, maps, and review platforms to ensure Name, Address, and Phone (NAP) data stays consistent. Inconsistent citations degrade local search rankings and confuse customers. This tool automates the discovery, comparison, and alerting workflow so you can fix listing errors before they impact revenue.

  • Audit NAP consistency across 80+ directories and data aggregators
  • Detect duplicate and near-duplicate listings automatically
  • Monitor citation drift with scheduled scans and real-time alerts
  • Export findings as CSV, JSON, or PDF for reporting and remediation
  • REST API for integration into agency dashboards and SEO pipelines

Quick Start

# Install via pip
pip install edgeiq-listing-aggregator

# Run an initial NAP audit for a business
listing-aggregator audit --name "Acme Plumbing" --phone "555-0100" --address "123 Main St, Austin, TX 78701"

# Scan for duplicates across all tracked directories
listing-aggregator duplicates scan --business-id biz_abc123

# Enable continuous citation drift monitoring
listing-aggregator monitor start --business-id biz_abc123 --interval daily --alert-webhook https://hooks.example.com/drift

The initial audit typically completes within 2–5 minutes depending on the number of directories queried. Results are stored locally in ~/.edgeiq/listings.db and available immediately via CLI or API.

NAP Matching Rules

Exact string matching fails on real-world directory data. Business Listing Aggregator uses a layered normalization and fuzzy-matching pipeline to accurately compare NAP fields.

Normalization Steps

  1. Case folding: All text lowercased before comparison.
  2. Punctuation stripping: Periods, commas, and hyphens removed from abbreviations (e.g., “St.” → “st”, “Ste 200” → “suite 200”).
  3. Phone normalization: Stripped to digits only; country codes handled via E.164 parsing.
  4. Address standardization: USPS-style abbreviation expansion (e.g., “Rd” → “Road”, “Blvd” → “Boulevard”).

Match Thresholds

FieldAlgorithmDefault ThresholdOverride Flag
NameToken-set ratio + Jaro-Winkler0.85--name-threshold 0.9
AddressNormalized Levenshtein0.90--address-threshold 0.8
PhoneDigit-exact match1.00--phone-fuzzy (allows extension diffs)
Lower thresholds increase recall but may produce false positives. For high-volume agency use, start with defaults and tune per client based on initial audit results.

Match Statuses

  • Exact — Normalized values match perfectly.
  • Partial — Score falls between threshold and exact; flagged for manual review.
  • Mismatch — Score below threshold; likely incorrect or outdated listing.

Duplicate Detection

Duplicate listings split reviews, confuse customers, and dilute local search authority. The duplicate detector clusters listings that likely represent the same business entity.

Detection Methods

  • Geographic proximity: Listings within 50 meters sharing a similar name are flagged as potential duplicates.
  • Phone overlap: Identical normalized phone numbers across different directory entries trigger automatic grouping.
  • Name similarity clustering: DBSCAN-based clustering on normalized name tokens groups variants like “Acme Plumbing Co” and “Acme Plumbing Company”.
  • Website backlink: Listings pointing to the same canonical URL are merged into one cluster regardless of NAP variance.

CLI Usage

# Run duplicate scan
listing-aggregator duplicates scan --business-id biz_abc123

# Review detected clusters interactively
listing-aggregator duplicates review --business-id biz_abc123

# Merge confirmed duplicates (marks secondary listings for suppression)
listing-aggregator duplicates merge --cluster-id cl_xyz789 --primary listing_google_001

Suppression Workflow

After merging, the tool generates a suppression request file compatible with major aggregators (Data Axle, Neustar/Localeze, Foursquare). Submit these files through each aggregator’s portal or via the API if supported.

Citation Drift Alerts

Citation drift occurs when a previously consistent listing changes without authorization — a directory reformats your address, a user suggests an edit, or a scraper overwrites your phone number. Continuous monitoring catches these changes early.

Monitoring Setup

# Start daily monitoring
listing-aggregator monitor start --business-id biz_abc123 --interval daily

# Configure alert destinations
listing-aggregator monitor config --business-id biz_abc123 \
  --alert-email seo@example.com \
  --alert-webhook https://hooks.slack.com/services/T00/B00/xxx

Alert Types

Alert Suppression

Suppress noisy alerts during planned migrations or rebrands:

listing-aggregator monitor suppress --business-id biz_abc123 --reason "Rebrand in progress" --until 2026-12-31
Suppressed alerts are still logged internally and appear in audit history. They are simply not delivered to configured notification channels.

Troubleshooting

Common Issues

Audit returns zero listings found: Verify the business name isn’t overly generic. Add --website to help the crawler disambiguate. Some directories block automated queries; check ~/.edgeiq/logs/audit.log for 403/429 responses.

False positive duplicates: Businesses with similar names in the same city (e.g., franchise locations) may cluster incorrectly. Increase the geographic proximity threshold with --dup-distance 200 (meters) or manually exclude via listing-aggregator duplicates ignore --listing-id dir_123.

Drift alerts firing constantly: Some directories normalize addresses differently on every scrape. If a specific directory produces persistent partial-match noise, suppress it: listing-aggregator monitor suppress-dir --business-id biz_abc123 --directory problematic-dir.

Phone number mismatch despite correct number: International formatting differences cause digit mismatches. Always provide canonical phone in E.164 format (+15550100). Use --phone-fuzzy to allow extension variations.

PDF export missing logo or branding: Ensure the --logo path points to a PNG or SVG under 2MB. Raster images above 1000px wide are auto-scaled. Check ~/.edgeiq/logs/export.log for rendering errors.

API returns 401 Unauthorized: Confirm your API key hasn’t expired or been rotated. Generate a new key at edgeiqlabs.com/account. Keys prefixed ei_test_ only work against sandbox endpoints.
