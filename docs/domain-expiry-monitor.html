Overview

Domain Expiry Monitor continuously tracks your domain registration dates and sends configurable alerts well before expiration. Designed for developers, agencies, and businesses that manage multiple domains and cannot afford accidental lapses. The monitor queries WHOIS data on a scheduled basis, normalizes expiry dates across registrars, and delivers notifications through email, webhooks, or integrations so you always have time to renew.

  • Monitor unlimited TLDs with automatic WHOIS server detection
  • Configurable alert thresholds (e.g., 90, 60, 30, 7 days before expiry)
  • Bulk import via CSV or API for large domain portfolios
  • REST API for integration into dashboards, ticketing systems, and CI/CD pipelines
  • Detailed historical tracking of registration changes and renewal events

Setup

Adding Domains

Add domains individually via the CLI or dashboard. The monitor automatically resolves the correct WHOIS endpoint for each TLD.

# Add a single domain
domain-monitor add example.com

# Add multiple domains at once
domain-monitor add example.com example.org example.net

# List all monitored domains
domain-monitor list

# Check current status of a domain
domain-monitor status example.com

WHOIS Configuration

Domain Expiry Monitor uses intelligent WHOIS resolution out of the box, but custom configurations are available for private registries, rate-limited endpoints, or proxy requirements.

SettingFlag / Config KeyDescription
Custom WHOIS Server--whois-serverOverride the default WHOIS endpoint for a specific domain
WHOIS Proxy--proxyRoute WHOIS queries through an HTTP/SOCKS proxy
Query Interval--intervalHow often to poll WHOIS data (default: daily)
Rate Limit Delay--rate-delaySeconds to wait between bulk WHOIS queries to avoid throttling
Auth Token--auth-tokenAPI key for RDAP or premium WHOIS services requiring authentication
# Configure a custom WHOIS server for a specific domain
domain-monitor config example.com --whois-server whois.custom-registry.com

# Set global query interval to every 12 hours
domain-monitor config --global --interval 12h

# Route queries through a proxy
domain-monitor config --global --proxy socks5://127.0.0.1:9050
WHOIS servers enforce strict rate limits. When monitoring more than 50 domains, use --rate-delay 2 or switch to RDAP where supported to prevent temporary IP bans.

Alert Configuration

Configure when and how you receive expiration warnings. Multiple channels and thresholds can be combined per domain or applied globally.

# Set alert thresholds (days before expiry)
domain-monitor alerts set example.com --thresholds 90,60,30,7

# Configure email alerts
domain-monitor alerts config --email admin@example.com

# Configure webhook alerts (Slack, Discord, generic)
domain-monitor alerts config --webhook https://hooks.slack.com/services/xxx

# Test alert delivery
domain-monitor alerts test example.com

# Disable alerts for a specific domain
domain-monitor alerts disable example.com
ChannelConfigurationNotes
Email--email <address>Supports multiple comma-separated addresses
Webhook--webhook <url>Sends JSON payload; compatible with Slack/Discord/custom endpoints
SMS--sms <number>Requires Twilio or compatible provider credentials in config

{

Bulk Import

Import large domain portfolios quickly using CSV files or the REST API. The bulk importer validates domains, deduplicates entries, and applies default alert configurations automatically.

# Import from a CSV file (one domain per line, optional columns for tags/thresholds)
domain-monitor import --file domains.csv

# Import from a plain text list
domain-monitor import --file domains.txt

# Export currently monitored domains to CSV
domain-monitor export --file backup.csv

CSV Format

ColumnRequiredDescription
domainYesThe fully qualified domain name
tagsNoComma-separated labels for grouping (e.g., production,client-a)
alert_thresholdsNoCustom thresholds overriding defaults (e.g., 90,30,7)
notesNoInternal notes or registrar reference numbers
Imports process asynchronously. Use domain-monitor import status <job_id> to track progress. Failed rows are written to a separate error log for review.

API Reference

All CLI functionality is available via REST API when running domain-monitor serve --port 8400. Authenticate requests using the X-API-Key header.

Endpoints

MethodPathDescription
GET/api/v1/domainsList all monitored domains with status
POST/api/v1/domainsAdd a new domain to monitor
GET/api/v1/domains/{domain}Retrieve details and WHOIS data for a specific domain
DELETE/api/v1/domains/{domain}Remove a domain from monitoring
PUT/api/v1/domains/{domain}/alertsUpdate alert configuration for a domain
POST/api/v1/importTrigger a bulk import job (multipart CSV upload)
GET/api/v1/import/{job_id}Check bulk import job status

Example: Add Domain via API

curl -X POST http://localhost:8400/api/v1/domains \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key_here" \
  -d '{
    "domain": "example.com",
    "tags": ["production", "primary"],
    "alert_thresholds": [90, 60, 30, 7]
  }'

Example: Retrieve Domain Status

curl -X GET http://localhost:8400/api/v1/domains/example.com \
  -H "X-API-Key: your_api_key_here"

Troubleshooting

Common Issues

WHOIS query returns no expiry date: Some ccTLDs and privacy-focused registrars redact expiry data. Try switching to RDAP (--use-rdap) or configure a custom WHOIS parser for that registry.

Rate limited by WHOIS server: Increase the delay between queries with --rate-delay 5. For large portfolios, distribute queries across multiple IPs or use a premium WHOIS/RDAP API provider.

Alerts not firing at expected times: Verify thresholds with domain-monitor alerts list <domain>. Ensure the background polling service is running (domain-monitor service status) and check logs at ~/.edgeiq/logs/domain-monitor.log.

Import fails silently: Validate your CSV format against the schema above. Ensure domains do not include protocols (http://) or paths. Check the generated error log in the working directory for row-specific failures.

False expiry dates after transfer: Domain transfers sometimes reset or alter registration dates. Trigger a manual refresh with domain-monitor refresh example.com to force a fresh WHOIS lookup and update the stored record.
