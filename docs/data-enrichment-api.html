Overview

The Data Enrichment API provides real-time B2B intelligence by accepting a company domain and returning structured business data. Ideal for sales teams, marketing automation, CRM enrichment, and lead qualification workflows.

  • Company size, revenue range, and founding year
  • Industry classification (NAICS/SIC) and sub-vertical tags
  • Technology stack detection (CMS, analytics, cloud providers)
  • Verified decision-maker contacts with role/title
  • Social profiles, funding history, and headquarters location

Setup

API Key Authentication

All requests require an API key passed in the X-API-Key header. Generate your key from the EdgeIQ Dashboard.

curl -H "X-API-Key: ei_live_abc123..." \
  https://api.edgeiqlabs.com/api/enrich?domain=example.com
Never expose your API key in client-side code or public repositories. Use environment variables or secret managers in production.

Troubleshooting

Common Issues

401 on valid key: Ensure you're using the live key prefix ei_live_ for production. Test keys (ei_test_) only work against the sandbox endpoint.

Empty contacts array: Some domains have no publicly verifiable decision-makers. Try broadening fields or checking meta.confidence_score.

Stale tech stack: Tech detection refreshes every 30 days. Use ?force_refresh=true (Pro only) to trigger an immediate re-scan.

Timeouts on large enterprises: Domains with 50k+ employees may take 2-3 seconds. Set client timeout to ≥5s.
