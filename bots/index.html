FAQ

Common questions

What languages do you support?

Node.js (discord.js, Eris, Sapphire), Python (discord.py, nextcord, pycord), Java (JDA), and Deno. If your bot runs in one of these runtimes, it'll work.

Will my bot stay online 24/7?

Yes. Unlike Replit or free tiers that sleep your process after inactivity, your bot runs continuously on dedicated hardware. It also auto-restarts if it ever crashes.

How do I upload my bot files?

You get access to a Pterodactyl web panel with a built-in file manager. You can drag and drop files directly in the browser, or connect via SFTP using FileZilla or VS Code.

Can I store environment variables / tokens securely?

Yes. The panel has a dedicated environment variables section. Your bot token never needs to be hardcoded in your files.

What if my bot crashes?

It auto-restarts immediately. You can also view live console output and logs at any time from the panel.

Is there a contract?

None. Month-to-month, cancel anytime, no questions asked.
