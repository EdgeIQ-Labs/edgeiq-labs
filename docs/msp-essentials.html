Setup

MSP Account Creation

# Register as MSP partner

  -H "Content-Type: application/json" \
  -d '{
    "company": "Acme IT Services",

    "plan": "starter"
  }'

Client Provisioning

# Create new client tenant
curl -X POST https://api.edgeiqlabs.com/v1/msp/clients \
  -H "Authorization: Bearer msp_token_xxx" \
  -d '{
    "name": "Widget Corp",
    "contact_email": "it@widgetcorp.com",
    "scan_targets": ["192.168.1.0/24", "10.0.0.0/16"],
    "report_schedule": "weekly"
  }'

# Bulk import via CSV
curl -X POST https://api.edgeiqlabs.com/v1/msp/clients/import \
  -H "Authorization: Bearer msp_token_xxx" \
  -F "file=@clients.csv"

White-Label Reports

Generate fully branded PDF reports that appear as if produced by your own security team. Customize logos, colors, domains, and executive summary language.

Branding Configuration

# Upload branding assets
curl -X POST https://api.edgeiqlabs.com/v1/msp/branding \
  -H "Authorization: Bearer msp_token_xxx" \
  -F "logo=@logo.png" \
  -F "primary_color=#1a73e8" \
  -F "company_name=Acme IT Services" \
  -F "support_email=security@acme-it.com" \
  -F "footer_text=Confidential - Acme IT Services"

# Apply branding to client
curl -X PATCH https://api.edgeiqlabs.com/v1/msp/clients/cli_xxx \
  -H "Authorization: Bearer msp_token_xxx" \
  -d '{"branding_id": "brd_abc123"}'

Bulk Licensing

Manage scanner licenses across your client base with volume pricing and automatic allocation.

License Management

# View license pool
curl https://api.edgeiqlabs.com/v1/msp/licenses \
  -H "Authorization: Bearer msp_token_xxx"

# Allocate licenses to client
curl -X POST https://api.edgeiqlabs.com/v1/msp/licenses/allocate \
  -H "Authorization: Bearer msp_token_xxx" \
  -d '{
    "client_id": "cli_xxx",
    "scanner_type": "port_scanner_pro",
    "quantity": 5
  }'

# Revoke unused licenses
curl -X DELETE https://api.edgeiqlabs.com/v1/msp/licenses/lic_abc \
  -H "Authorization: Bearer msp_token_xxx"
Unused licenses auto-return to pool after 30 days of inactivity. Over-allocation triggers upgrade prompt at next billing cycle.

Authentication

# All requests require Authorization header
Authorization: Bearer msp_live_xxxxxxxxxxxx

# Token scopes:
# msp:read      - Read-only access to clients and reports
# msp:write     - Create/update clients and generate reports
# msp:admin     - License management and branding config
# msp:billing   - Plan changes and invoice access

Troubleshooting

Common Issues

Client provisioning fails with 403: Verify MSP token has msp:write scope. Regenerate token in dashboard under Settings → API Keys.

White-label report shows EdgeIQ branding: Confirm branding_id is correctly assigned to client. Re-upload logo if PNG exceeds 2MB or uses CMYK color space.

License allocation returns insufficient_quota: Check current usage vs. plan limits at /v1/msp/licenses. Upgrade plan or revoke unused licenses first.

Dashboard shows stale risk scores: Trigger manual rescan via POST /v1/msp/clients/{id}/rescan. Scores update within 5 minutes of scan completion.

Webhook alerts not delivering: Test endpoint with POST /v1/msp/webhooks/test. Ensure target accepts POST with application/json content type and responds 2xx within 10s.
