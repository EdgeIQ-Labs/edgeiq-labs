Your AI Agents Are Breaking Things in Production. Here Is How We Catch Them.

Everyone shipped AI agents this year. The demos look incredible. Then someone deploys one and it starts clicking the wrong buttons at 2am — not because the model is dumb, but because the UI changed.

Everyone shipped AI agents this year. Click buttons, fill forms, navigate dashboards. The demos look incredible.

Then someone deploys one and it starts clicking the wrong buttons at 2am. Not because the model is dumb. Because the UI changed, a modal popped up, or the agent got confused by a loading state that took 400ms longer than expected.

We built Sentinel because we kept watching this happen. Not in testing. In production. With real customers seeing broken workflows.

What Sentinel Actually Does

Sentinel watches your AI agents work. It uses Playwright to see what the page renders, an LLM to decide if that matches what should be happening, and then executes fixes when something drifts.

It does not run assertions someone wrote six months ago. Those break every time a CSS class changes or a button moves two pixels. Sentinel looks at the actual accessibility tree and decides if the outcome is correct.

The loop works like this:

  1. Agent performs an action
  2. Sentinel captures the ariaSnapshot of what rendered
  3. LLM evaluates whether the result matches intent
  4. If it does not, Sentinel executes a correction or flags it for review
  5. Everything gets logged with screenshots and reasoning

You get a dashboard showing every decision, every pass, every failure, and why the model thought what it thought.

Why This Matters for Small Teams

Enterprise QA teams have 40 people maintaining Selenium suites. You have two developers and a product to ship.

When your AI agent breaks something silently, you find out from a customer complaint three days later. By then the logs are rotated and nobody remembers what version was running.

Sentinel gives you the monitoring layer without hiring a QA department. The open source core handles the detection loop. The managed tier adds the dashboard, alerting, and project tracking if you do not want to self-host the infrastructure.
