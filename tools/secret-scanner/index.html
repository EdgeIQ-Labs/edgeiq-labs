Does this tool upload my code?
No. All scanning happens in your browser using JavaScript regex matching. Your code, config files, and secrets never leave your machine. Open your Network tab to verify zero outbound requests.
What secret patterns does this detect?
Stripe API keys, GitHub personal access tokens, AWS access keys, Slack tokens, Google API keys, JWT tokens, private key blocks, hardcoded password assignments, generic API key patterns, and connection strings.
How is this different from the Repo Scanner?
This tool scans text you paste directly — ideal for quick checks on config snippets, log output, or code fragments. The Repo Scanner analyzes an entire GitHub repository automatically, checking file trees, gitignore coverage, CI configs, and Supabase RLS policies.
What should I do if secrets are found?
Rotate every exposed credential immediately. Remove the secret from code and move it to environment variables or a secrets manager. If committed to git, assume it's compromised even after deletion — git history retains old versions indefinitely.
