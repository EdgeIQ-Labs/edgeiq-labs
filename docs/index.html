Option 2 — REST API

Integrate EdgeIQ Labs scanners directly into your own tools, CI/CD pipelines, or dashboards. All APIs use standard HTTP requests with JSON responses.

Step 1 — Get your API key

Sign up at edgeiqlabs.com/pricing and generate an API key from your dashboard. Free tier includes limited scans per month.

Step 2 — Make a request

Send a POST request to any scanner endpoint with your target and API key:

curl -X POST https://edgeiqlabs.com/api/repo-scanner \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json" \
  -d '{"repo": "https://github.com/example/repo"}'

Step 3 — Parse the response

All endpoints return structured JSON with findings, severity ratings, and remediation guidance. Check each product's doc page for endpoint-specific schemas.

✓ Free Tier — What's Included
  • Limited scans per month (varies by tool)
  • All basic scanner features
  • JSON response format
  • Community support
★ Paid Tier — Everything in Free, Plus
