API Reference

All endpoints require authentication via Authorization: Bearer <key> or X-API-Key: <key> header.

POST /api/v1/repo-scan

Scan a GitHub repository for leaked secrets, missing .gitignore, and RLS gaps.

curl -X POST https://edgeiqlabs.com/api/v1/repo-scan \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://github.com/org/repo"}'
GET /api/v1/header-check?domain=example.com

Analyze HTTP security headers (HSTS, CSP, X-Frame-Options, etc.) for any domain.

curl -H "Authorization: Bearer YOUR_KEY" \
  "https://edgeiqlabs.com/api/v1/header-check?domain=example.com"
GET /api/v1/ssl-check?domain=example.com

Check SSL certificate validity, HTTPS enforcement, HSTS, and security headers.

curl -H "Authorization: Bearer YOUR_KEY" \
  "https://edgeiqlabs.com/api/v1/ssl-check?domain=example.com"
GET /api/v1/dns-check?domain=example.com

Lookup DNS records (A, AAAA, MX, TXT, NS, CNAME) for any domain.

curl -H "Authorization: Bearer YOUR_KEY" \
  "https://edgeiqlabs.com/api/v1/dns-check?domain=example.com"
GET /api/v1/breach-check?email=user@example.com

Check if an email address has been exposed in known data breaches.

curl -H "Authorization: Bearer YOUR_KEY" \
  "https://edgeiqlabs.com/api/v1/breach-check?email=user@example.com"

Response Format

All responses include API metadata in the _api field:

{
  "grade": "A",
  "score": 92,
  "findings": [...],
  "_api": {
    "tier": "pro",
    "remaining_requests": 87,
    "rate_limit": 100
  }
}

Error Codes

401 — Missing or invalid API key

403 — Key revoked or expired

429 — Rate limit exceeded (check Retry-After header)

500 — Internal error
