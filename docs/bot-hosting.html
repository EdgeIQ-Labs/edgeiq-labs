Setup

Git Deploy

Connect your repository to deploy via Git push. The build system automatically detects your bot framework and installs dependencies.

# Add EdgeIQ as a remote
git remote add edgeiq https://git.edgeiqlabs.com/bots/my-discord-bot.git

# Push to deploy
git push edgeiq main

# Deploy a specific branch
git push edgeiq feature/auto-mod:main
Supported languages: Node.js (18/20), Python (3.10/3.11/3.12), Go, Rust. Include a package.json, requirements.txt, or Cargo.toml in your repo root for auto-detection.

Environment Variables

Store secrets securely without committing them to source control. Variables are encrypted at rest and injected into the runtime environment.

# Set variables via CLI
edgeiq bot env set DISCORD_TOKEN=MTE... --bot my-discord-bot
edgeiq bot env set DATABASE_URL=postgres://... --bot my-discord-bot

# List current variables (values masked)
edgeiq bot env list --bot my-discord-bot

# Remove a variable
edgeiq bot env unset DEBUG_MODE --bot my-discord-bot

Variables can also be managed through the web dashboard under Bots → Settings → Environment. Changes trigger an automatic graceful restart unless --no-restart is specified.

Bot Configuration

Create an edgeiq.yaml file in your repository root to customize runtime behavior:

# edgeiq.yaml
runtime:
  language: node
  version: "20"
  command: "node dist/index.js"
  
restart:
  policy: always          # always | on-failure | never
  max_restarts: 10        # within window below
  restart_window: 3600    # seconds
  backoff_multiplier: 2   # exponential backoff on repeated crashes

resources:
  memory: 512             # MB (Starter: 512, Pro: 2048)
  cpu: 0.5                # vCPU cores

logs:
  retention_days: 7       # Starter: 7, Pro: 30
  max_size_mb: 100        # per-session cap
  stream: true            # enable real-time streaming
FieldDefaultDescription
restart.policyalwaysWhen to restart after exit
restart.max_restarts10Max restarts within window before giving up
resources.memory512RAM allocation in MB
logs.retention_days7How long logs are stored

Log Streaming

View bot output in real time through the dashboard, CLI, or WebSocket API.

# Stream logs via CLI
edgeiq bot logs tail my-discord-bot --follow

# Filter by level
edgeiq bot logs tail my-discord-bot --level error

# Download historical logs
edgeiq bot logs download my-discord-bot --from 2026-11-01 --format json

WebSocket endpoint for programmatic access:

wss://api.edgeiqlabs.com/v1/bots/{bot_id}/logs/stream
Authorization: Bearer <API_KEY>
Logs are buffered and flushed every 200ms. Stdout and stderr are merged with source tags ([OUT] / [ERR]). Use structured JSON logging for parseable output.

Auto-Restart

The supervisor monitors your bot process continuously. Restart behavior is configurable per bot:

PolicyBehaviorUse Case
alwaysRestart on any exit codeProduction bots that must stay online
on-failureRestart only on non-zero exitDevelopment/testing environments
neverNever auto-restartOne-shot scripts, maintenance tasks

Exponential backoff prevents restart loops: if a bot crashes repeatedly within the configured window, wait times double (1s → 2s → 4s → ...) up to 60 seconds. After max_restarts failures, the bot enters a crashed state and requires manual intervention.

# Check restart history
edgeiq bot status my-discord-bot

# Manual restart
edgeiq bot restart my-discord-bot

# Clear crash counter
edgeiq bot reset-restarts my-discord-bot

Troubleshooting

Common Issues

Bot stuck in restart loop: Check logs for unhandled exceptions or missing environment variables. Run edgeiq bot logs tail {id} --level error to isolate the failure. Verify edgeiq.yaml restart policy isn't masking a fatal configuration error.

Deploy fails silently: Ensure your repo has a valid dependency manifest (package.json, requirements.txt, etc.). Check build logs via edgeiq bot logs {id} --session latest-build. Unsupported language versions return exit code 127.

Environment variables not updating: Variables require a restart to take effect. Use edgeiq bot env set KEY=val --bot {id} (auto-restarts) or manually restart after bulk updates via API.

Memory limit exceeded: Bots exceeding allocated RAM are OOM-killed and restarted. Upgrade to Pro ($15/mo) for 2GB RAM, or optimize your bot's memory footprint. Monitor usage via edgeiq bot metrics {id}.

Git push rejected: Verify your SSH key or HTTPS credentials are linked to your EdgeIQ account. Run edgeiq auth status to check. Force-push is disabled on production branches by default.
