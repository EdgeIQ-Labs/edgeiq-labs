Setup Guide

Free Badge Setup

The free badge is automatically generated after completing a security scan. No account or payment required.

  1. Scan your domain using any tool at edgeiqlabs.com/free-domain-security-score
  2. Click "Get Your Free Badge" on the results page
  3. Copy the generated embed snippet
  4. Paste the script tag into your website footer
<!-- Free Badge Embed -->
<script src="https://edgeiqlabs.com/badge.js" 
        data-badge-id="YOUR_BADGE_ID"></script>

Verified Badge Setup

The Verified Badge requires an active subscription. After purchase, configure your badge via the dashboard or API.

  1. Purchase via the landing page or checkout API
  2. Upload your company logo in the dashboard
  3. Enable white-label mode if desired (removes EdgeIQ branding)
  4. Use the verified embed script instead of the free version
<!-- Verified Badge Embed -->
<script src="https://edgeiqlabs.com/verified-badge.js" 
        data-badge-id="YOUR_VERIFIED_BADGE_ID"></script>
The Verified Badge script includes all free tier functionality plus premium features. Do not include both scripts on the same page.

API Reference

All badge operations are available via REST API. The checkout endpoint redirects to Stripe; data endpoints return JSON.

Endpoints

MethodPathDescription
GET/api/badge?id=BADGE_IDRetrieve free badge data (grade, score, last scan)
GET/api/verified-badge?id=BADGE_IDRetrieve verified badge data (logo URL, verification URL, settings)
POST/api/verified-badgeCreate or update verified badge configuration (webhook use)
GET/api/badge-checkout?domain=X&email=YRedirect to Stripe checkout for $99/yr subscription

Example: Fetch Free Badge Data

curl "https://edgeiqlabs.com/api/badge?id=abc123"

# Response:
{
  "badge_id": "abc123",
  "domain": "example.com",
  "grade": "A",
  "score": 92,
  "last_scan": "2026-11-18T14:30:00Z",
  "report_url": "https://edgeiqlabs.com/report/abc123"
}

Example: Fetch Verified Badge Data

curl "https://edgeiqlabs.com/api/verified-badge?id=vxyz789"

# Response:
{
  "badge_id": "vxyz789",
  "domain": "example.com",
  "grade": "A",
  "score": 92,
  "logo_url": "https://cdn.edgeiqlabs.com/logos/vxyz789.png",
  "verification_url": "https://edgeiqlabs.com/verify/vxyz789",
  "white_label": true,
  "glow_enabled": true
}

Example: Create/Update Verified Badge (Webhook)

curl -X POST "https://edgeiqlabs.com/api/verified-badge" \
  -H "Content-Type: application/json" \
  -d '{
    "badge_id": "vxyz789",
    "logo_url": "https://example.com/logo.png",
    "white_label": true,
    "glow_enabled": true
  }'

The POST endpoint is primarily used by internal webhooks after Stripe checkout completion or dashboard updates. External callers should use the dashboard for configuration changes.

Checkout Integration

To programmatically initiate a Verified Badge purchase, redirect users to the checkout endpoint:

https://edgeiqlabs.com/api/badge-checkout?domain=example.com&email=admin@example.com

Parameters:

  • domain (required): The domain to associate with the badge
  • email (required): Customer email for receipt and dashboard access

This redirects to Stripe Checkout with price ID price_1UcOIGRC1NZ20yDTpuXPodLz ($99/yr). After successful payment, a webhook automatically provisions the verified badge.

Embed Script Behavior

badge.js (Free Tier)

  • Fetches grade data from /api/badge on load
  • Renders inline SVG with grade letter and score
  • Links to full report URL
  • Includes "Verified by EdgeIQ Labs" text
  • Caches response for 1 hour to reduce API calls

verified-badge.js (Premium Tier)

  • Fetches data from /api/verified-badge on load
  • Renders custom logo if configured
  • Applies purple glow CSS effect when glow_enabled is true
  • Links to public verification URL instead of report
  • Hides EdgeIQ branding when white_label is true
  • Falls back to free badge styling if verified data unavailable

Troubleshooting

Common Issues

Badge not displaying: Verify the data-badge-id attribute matches your assigned ID. Check browser console for CORS errors or network failures. Ensure the script tag is placed in the document body, not head.

Grade shows stale data: Badges cache API responses for 1 hour. Trigger a new scan at /free-domain-security-score to update. Wait 5 minutes after scanning for cache propagation.

Verified badge showing free tier styling: Confirm your subscription is active and the badge ID is correct. Check that you're using verified-badge.js, not badge.js. Verify logo upload completed successfully in dashboard.

Logo not appearing: Supported formats: PNG, JPG, SVG. Max file size: 2MB. Recommended dimensions: 200x60px. Transparent backgrounds preferred. Re-upload via dashboard if corrupted.

White-label still shows EdgeIQ branding: Toggle white-label off and on in dashboard to force sync. Clear browser cache. Allow up to 10 minutes for CDN propagation after setting change.

Checkout redirects to error page: Verify both domain and email parameters are present and valid. Ensure domain is not already associated with another active subscription. Contact support if issue persists.

API returns 404: Badge IDs are case-sensitive. Free and verified badge IDs are distinct namespaces. Confirm you're calling the correct endpoint (/api/badge vs /api/verified-badge).
