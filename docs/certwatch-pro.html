Overview

CertWatch Pro continuously monitors your SSL/TLS certificates across all domains, tracking expiry dates, chain validity, and configuration issues. Built on Certificate Transparency (CT) log integration, it provides real-time visibility into certificate issuance and revocation without requiring agent installation or server access.

  • Monitor certificate expiry with alerts at 30, 14, 7, and 1 days before expiration
  • Validate full certificate chains including intermediate and root CAs
  • Detect misconfigurations: incomplete chains, hostname mismatches, weak signatures
  • Track new certificate issuance via CT log monitoring
  • REST API for integration into DevOps workflows and SOAR platforms

Setup

Adding Domains

Add domains to monitor via the dashboard or API. CertWatch Pro automatically discovers subdomains and associated certificates through CT log queries.

# Add a domain via CLI
certwatch add example.com

# Add multiple domains
certwatch add example.com api.example.com mail.example.com

# Import from existing inventory
certwatch import --file domains.csv

Notification Channels

# Configure email alerts
certwatch alert config --channel email --to admin@example.com

# Configure Slack webhook
certwatch alert config --channel slack --webhook https://hooks.slack.com/services/xxx

# Configure generic webhook
certwatch alert config --channel webhook --url https://api.example.com/cert-alert

# Test alert delivery
certwatch alert test --channel email

Webhook payloads include certificate details, expiry timestamp, chain status, and direct links to the CertWatch dashboard for remediation.

Troubleshooting

Common Issues

Certificate not appearing in dashboard: Verify the domain is added and CT log indexing is complete. New certificates may take 15-60 minutes to appear in CT logs. Use Direct Probe mode for immediate verification.

False positive chain errors: Some servers intentionally serve incomplete chains for legacy clients. CertWatch flags these as warnings. Suppress with --ignore-incomplete-chain if validated as intentional.

Alerts not delivering: Test channel configuration with certwatch alert test. Check webhook endpoint returns HTTP 2xx. Email delivery may be delayed 30-60 seconds due to webhook processing.

Private CA certificates missing: CT logs only cover publicly trusted CAs. For internal PKI, configure Direct Probe with custom trust store via certwatch config --trust-store /path/to/ca-bundle.pem.

Rate limiting on API calls: Starter plans allow 100 requests/hour, Pro plans allow 1000 requests/hour. Implement exponential backoff for batch operations. Contact support for higher limits.
