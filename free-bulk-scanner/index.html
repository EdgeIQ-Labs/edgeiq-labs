Frequently asked questions

What does each grade mean?
Grade A means all four checks passed — valid SSL, security headers present, SPF record found, and DMARC record found. Grade B means 1 check failed. Grade C means 2 failures. Grade D means 3 failures. Grade F means all 4 checks failed or the domain was completely unreachable.
How is this different from individual scanners?
Individual scanners like our Domain Security Score tool check one domain at a time. The Bulk Scanner lets you paste up to 20 domains and runs every check in parallel, returning a single unified table. It's built for agencies, developers, and teams managing multiple properties who need a fast portfolio-wide security snapshot.
Can I export results?
Results are currently displayed on screen. You can select and copy the table directly, or use your browser's Print function (Ctrl/Cmd + P) to save it as a PDF. We're considering CSV export for a future update.
