Fix-It Engine

Automate remediation steps from EdgeIQ findings.

Setup

Enable Fix-It with any compatible tool plan and define action policies per severity.

  • Auto SSL Renew
  • Header Auto-Fix
  • GitHub Issue Creator

How to Use

  1. Set approval mode (auto vs human-review).
  2. Map findings to actions and cooldown windows.
  3. Run in dry-run for 7 days before full automation.

Troubleshooting

  • Too many actions: raise severity threshold and add dedupe.
  • No actions firing: verify webhook/credential config.
