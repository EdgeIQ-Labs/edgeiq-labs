Overview

Email Security Suite bundles four specialized email security tools into one integrated platform. Monitor your domain's authentication records, detect phishing attempts in real-time, inspect message headers for anomalies, and track your overall email security posture with weekly scores.

  • SPF/DMARC/DKIM Monitor: Continuous DNS record validation and alerting

Setup

Domain Verification

Add and verify domains to enable monitoring:

# Add domain to suite
email-security add-domain example.com

# Verify ownership via DNS TXT record
email-security verify example.com --method dns-txt

# List monitored domains
email-security domains list
Domain verification requires adding a TXT record to your DNS. No email content is accessed during setup.

Connecting Data Sources

Connect mail servers and security tools for comprehensive analysis:

# Connect Gmail/Workspace for header analysis
email-security connect gmail --account admin@example.com

# Connect Microsoft 365
email-security connect m365 --tenant-id xxxxx

# Configure DMARC report ingestion
email-security dmarc configure --rua-mailbox dmarc-reports@example.com

# Enable Slack alerts
email-security alerts slack --webhook https://hooks.slack.com/services/xxx

Phishing Detection

Analyze suspicious emails by forwarding them to scan@edgeiqlabs.com or submitting via API:

# Submit URL for analysis
email-security phish-analyze --url "https://suspicious-site.com/login"

# Scan attachment hash
email-security phish-analyze --sha256 abc123def456...

# Check sender reputation
email-security phish-analyze --sender attacker@spoofed.com
Phishing analysis runs in isolated sandboxes. Submitted samples are retained for 7 days for threat intelligence correlation.

Header Inspector

Paste raw headers or connect a mailbox to analyze routing paths and authentication failures:

# Analyze pasted headers
email-security headers analyze --input headers.txt

# Inspect specific message from connected inbox
email-security headers inspect --message-id "<abc123@mail.gmail.com>"

# Flag ARC chain breaks
email-security headers arc-validate --message-id "<xyz789@outlook.com>"

Weekly Security Score

Composite A-F grade calculated from auth records, phishing exposure, header hygiene, and dark web mentions:

# View current score
email-security score example.com

# View score trend
email-security score example.com --history 12w

# Download scorecard PDF
email-security score example.com --export pdf

Troubleshooting

Common Issues

DMARC reports not arriving: Verify RUA mailbox exists and accepts external mail. Check spam folder. Use email-security dmarc test-rua example.com to send a test report.

False positive phishing detection: Submit feedback with email-security phish-feedback --sample-id abc123 --verdict safe. Model retraining occurs weekly.

Header analysis incomplete: Some providers strip internal Received headers. Ensure you're pasting the full original headers, not forwarded content.

Score dropped unexpectedly: Check email-security score example.com --diff to see which factor changed. Common causes: expired DKIM key, new DMARC failure spike, or dark web credential leak.

API rate limit exceeded: Suite plan allows 1000 requests/hour. Upgrade to Enterprise for higher limits or implement request queuing.

Slack alerts not firing: Test webhook with email-security alerts test slack. Verify channel permissions and webhook URL hasn't been rotated.
