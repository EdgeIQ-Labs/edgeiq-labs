Overview

StatusPage provides customizable public status pages to communicate service health, incidents, and maintenance windows to your users. Includes real-time component status, historical uptime metrics, automated incident updates, and multi-channel subscriber notifications.

  • Custom-branded status pages with your domain
  • Real-time component status tracking
  • Incident timeline with automated updates
  • 90-day uptime history and SLA metrics
  • Email, SMS, webhook, and RSS subscriber notifications
  • REST API for CI/CD integration and automated incident creation

Setup

Creating a Status Page

# Create a new status page
statuspage create --name "My SaaS" --domain status.mysaas.com

# Add components to monitor
statuspage component add --name "API" --group "Core Services"
statuspage component add --name "Dashboard" --group "Core Services"
statuspage component add --name "Webhooks" --group "Integrations"

# List components
statuspage component list

Configuring Notifications

# Enable email subscriptions
statuspage config --email-notifications true

# Configure SMTP
statuspage config --smtp-host smtp.example.com --smtp-user alerts@example.com

# Enable SMS (Twilio)
statuspage config --sms-provider twilio --sms-from +1234567890

# Webhook for incident events
statuspage config --incident-webhook https://hooks.example.com/statuspage

# Test notification delivery
statuspage test-notification
Subscribers can choose their preferred notification channel. All channels receive identical incident updates for consistency.

Component Configuration

Auto-detect--auto-detecttrueAutomatically update status from monitors

Check interval--interval60Seconds between health checks
Degraded threshold--degraded-pct95Uptime % below which status = degraded
Outage threshold--outage-pct80Uptime % below which status = outage
Maintenance mode--maintenancefalseManually set component to maintenance
# Custom component monitoring
statuspage component config "API" \
  --uptime-check \
  --interval 30 \
  --degraded-pct 99 \
  --outage-pct 95

# Schedule maintenance window
statuspage maintenance schedule "Database Migration" \
  --start "2026-11-20T02:00:00Z" \
  --end "2026-11-20T04:00:00Z" \
  --components "API,Dashboard"

API Reference

All CLI functionality is available via REST API at /api/statuspage/.

Endpoints

MethodPathDescription
GET/api/statuspage/List all status pages
POST/api/statuspage/Create a new status page
GET/api/statuspage/{id}/componentsList components for a page
POST/api/statuspage/{id}/incidentsCreate a new incident
PATCH/api/statuspage/{id}/incidents/{incident_id}Update incident status
GET/api/statuspage/{id}/metricsRetrieve uptime metrics

Example: Create Incident via API

curl -X POST https://edgeiqlabs.com/api/statuspage/sp_abc123/incidents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "API Latency Spike",
    "status": "degraded_performance",
    "components": ["comp_api"],
    "message": "Investigating increased response times on /v2 endpoints."
  }'

# Response
{
  "id": "inc_xyz789",
  "status": "degraded_performance",
  "created_at": "2026-11-18T14:30:00Z",
  "updates": []
}

Troubleshooting

Common Issues

Status not updating automatically: Verify the linked monitor is active and returning data. Use statuspage component check "API" to run a manual health check and view last probe result.

Notifications not sending: Test with statuspage test-notification. Check SMTP logs for auth failures or rate limits. For SMS, verify Twilio balance and sender number registration.

Custom domain not resolving: Ensure CNAME record points to status.edgeiqlabs.com. Allow up to 24h for DNS propagation. Verify SSL certificate issued via statuspage ssl-status --domain status.mysaas.com.

Incident timeline out of order: All timestamps must be ISO 8601 UTC. Use --timestamp flag when posting updates manually to preserve chronological order.

Metrics showing gaps: Health checks may have been paused during maintenance. Use --backfill to import historical data from external monitoring sources.
