Vendor Risk Management

Documentation · EdgeIQ Labs

Overview

EdgeIQ Labs Vendor Risk Management is a compliance tracking platform designed for healthcare organizations and business associates. It centralizes vendor assessments, Business Associate Agreement (BAA) lifecycle management, and continuous risk monitoring into a single dashboard.

The system provides structured workflows for onboarding vendors, documenting security posture, tracking contract expiration dates, and maintaining audit-ready records of all third-party relationships.

Getting Started

Initial Setup

  1. Navigate to Settings → Organization and enter your legal entity name, address, and primary compliance officer contact.
  2. Configure your notification preferences under Settings → Alerts.
  3. Invite team members via Settings → Users and assign roles (Admin, Reviewer, Viewer).
  4. Create your first vendor assessment by selecting Vendors → Add New.

Adding Vendors

Each vendor record contains the following required fields:

  • Vendor Name: Legal name of the organization.
  • Contact Email: Primary point of contact for security inquiries.
  • Service Category: Classification (e.g., Cloud Hosting, SaaS, Medical Device, Billing).
  • Risk Tier: Internal classification (Low, Medium, High, Critical).
  • BAA Required: Boolean toggle indicating if PHI is accessed.

Optional fields include SOC 2 report upload, last audit date, and sub-processor list. All file uploads are encrypted at rest using AES-256.

BAA Tracking

The BAA module tracks the full lifecycle of Business Associate Agreements:

  • Status Indicators: Draft, Sent, Signed, Expired, Terminated.
  • Expiration Alerts: Configurable warnings at 90, 60, and 30 days prior to contract end.
  • Version History: Immutable log of all document revisions and signature timestamps.
  • Linked Assessments: Each BAA is automatically associated with the corresponding vendor risk assessment completed within the same fiscal year.

To upload a BAA, navigate to the vendor profile, select the Agreements tab, and drag-and-drop the signed PDF. The system extracts metadata (effective date, termination clause) via OCR for validation.

Alerts & Notifications

Notifications are delivered via email and in-app inbox. Alert triggers include:

  • BAA expiration or missing signature
  • Overdue annual reassessment
  • Critical risk score change (>20% variance)
  • New sub-processor added by vendor

Webhook Configuration

Configure outbound webhooks under Settings → Integrations → Webhooks. Payloads are sent as POST requests with HMAC-SHA256 signatures.

{
  "event": "baa.expiring",
  "timestamp": "2026-11-06T14:30:00Z",
  "vendor_id": "vnd_8f7a6b5c",
  "baa_id": "baa_3d2e1f0a",
  "days_remaining": 30,
  "severity": "warning"
}

API Reference

All endpoints require a Bearer token obtained from Settings → API Keys. Base URL: https://api.edgeiqlabs.com/v1

List Vendors

curl -X GET https://api.edgeiqlabs.com/v1/vendors \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json"

Create Assessment

curl -X POST https://api.edgeiqlabs.com/v1/assessments \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "vendor_id": "vnd_8f7a6b5c",
    "assessment_type": "annual",
    "risk_score": 72,
    "notes": "SOC 2 Type II reviewed, no exceptions noted."
  }'

Rate limit: 100 requests per minute per API key. Exceeding this returns HTTP 429 with a Retry-After header.

Troubleshooting

Common Issues

  • OCR fails on BAA upload: Ensure the PDF is text-based, not a scanned image. If scanned, use a resolution ≥300 DPI and ensure the document is not rotated.
  • Webhook delivery failures: Verify your endpoint returns HTTP 2xx within 5 seconds. Non-2xx responses trigger exponential backoff retries (max 8 attempts over 24 hours).
  • Missing vendor in dropdown: Only active vendors appear in assessment creation. Archived vendors must be restored via Vendors → Archive before linking.
  • API key invalid: Keys prefixed with sk_test_ only work against the sandbox environment (https://sandbox.api.edgeiqlabs.com/v1). Production requires sk_live_.
