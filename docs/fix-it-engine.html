Fix-It Engine Documentation

Overview

Fix-It Engine is a $9/mo add-on available with any compatible EdgeIQ scanner tool. It bridges the gap between finding a problem and fixing it by automating common remediation steps directly from scan results.

Supported Actions

  • Auto SSL Renewal: Automatically renews expiring certificates via Let's Encrypt when linked with CertWatch Pro
  • Header Auto-Fix: Injects missing security headers (HSTS, CSP, X-Frame-Options) into server configs
  • GitHub Issue Creator: Opens issues in your repo with finding details, severity, and suggested fix
  • Webhook Dispatch: Sends structured payloads to your CI/CD pipeline or ticketing system
  • DNS Record Correction: Fixes misconfigured SPF/DKIM/DMARC records via API (requires provider credentials)

Setup

Prerequisites

  • Active subscription to any compatible EdgeIQ scanner (UptimePing, XSS Scanner, Port Scanner, etc.)
  • Fix-It Engine add-on enabled in your dashboard ($9/mo)
  • Provider-specific credentials configured per action type

Enabling Per-Tool

  1. Navigate to your scanner dashboard
  2. Open Settings → Integrations → Fix-It Engine
  3. Toggle actions individually (each action can be enabled/disabled independently)
  4. Configure credentials for each enabled action

Approval Modes

  • Dry Run (default): Logs what would happen without executing. Recommended for first 7 days.
  • Human Review: Creates a pending action queue requiring manual approval before execution.
  • Auto-Approve: Executes immediately for findings below a configurable severity threshold.

Configuration

Severity Thresholds

Set per-action severity cutoffs. Example: auto-fix only critical and high findings, queue medium for review, ignore low.

Cooldown Windows

Prevent duplicate actions on the same finding within a configurable window (default: 24 hours).

Action Policies (YAML)

actions:
  ssl_renew:
    enabled: true
    mode: auto-approve
    severity_min: high
    cooldown: 48h
  header_fix:
    enabled: true
    mode: human-review
    targets:
      - nginx
      - cloudflare
  github_issue:
    enabled: true
    mode: auto-approve
    repo: myorg/security-findings
    labels: [auto-generated, fix-it]

GitHub OAuth Flow

For GitHub Issue Creator:

  1. Click Connect GitHub in Fix-It settings
  2. Authorize EdgeIQ Labs OAuth app
  3. Select repositories to grant issue-write access
  4. Tokens are stored encrypted; EdgeIQ never accesses your code

API Reference

POST /api/fix-it/execute

Trigger a specific remediation action.

Field Type Required Description
finding_id string Yes ID of the scanner finding to remediate
action string Yes Action type (e.g., ssl_renew, header_fix, github_issue)
dry_run boolean No Simulate without executing (default: false)

Response: { "status": "queued", "action_id": "uuid-v4" }

GET /api/fix-it/actions/ACTION_ID

Check action status. Replace ACTION_ID with the actual action identifier.

Returns: pending, approved, executing, completed, failed

GET /api/fix-it/queue

List all pending actions awaiting human review.

Billing

Troubleshooting

Actions not firing
Verify credentials are valid and action is enabled for the specific tool.
SSL renewal fails
Ensure domain resolves to a server you control and port 80 is accessible.
GitHub issues not created
Check OAuth token has not expired; re-authorize if needed.
Too many duplicate actions
Increase cooldown window or raise severity threshold.
Header fixes breaking site
Use dry-run mode first; review generated config before applying.
