Overview

Subdomain Hunter Pro combines passive certificate transparency (CT) log analysis, active DNS brute-forcing, and intelligent takeover detection into a single unified workflow. Designed for bug bounty hunters and pentesters who need comprehensive asset discovery without the noise.

Quick Start

# Install via pip
pip install subdomain-hunter-pro

# Run a basic scan
shp scan example.com --output results.json

# Enable all discovery modules
shp scan example.com --all-modules --takeover-check

Discovery Methods

Certificate Transparency Logs

Passively queries crt.sh, Certstream, and Google CT logs to find historically issued certificates. This method is silent and often reveals forgotten staging environments or dev subdomains.

DNS Brute-Force

Uses an optimized wordlist of 250k+ permutations with wildcard filtering. Supports custom resolvers and rate-limiting to avoid blocking.

Zone Transfer Checks

Automatically attempts AXFR/IXFR requests against discovered nameservers. Reports misconfigured BIND/PowerDNS instances immediately.

Takeover Detection

Identifies dangling CNAME records pointing to unclaimed cloud resources:

  • AWS S3 buckets / CloudFront distributions
  • GitHub Pages / Heroku apps
  • Azure / GCP storage endpoints
  • Shopify / WordPress / Ghost CMS

Each finding includes proof-of-concept validation to reduce false positives.

Troubleshooting

Rate limited by CT logs? Use the --proxy flag or enable residential rotation in config.

Missing subdomains? Combine CT + brute-force with --all-modules. Some internal assets never receive public certs.

False positive takeovers? Run shp validate --strict to perform HTTP-level confirmation before reporting.
